# VimaanAI
A web-based flight delay predictor for budget airlines in India (future AI Integration planned)
Roadmap:
Here’s your month-by-month roadmap for making VimaanAI future-ready while learning AI along the way.


---

## Month 1 – Build the Web-Based MVP (No AI yet)

Goal: Have something functional to show recruiters quickly.

### Week 1–2: Research & Setup

Decide tech stack: React.js (frontend) + Node.js/Express (backend) + PostgreSQL (database).

Research APIs (AviationStack, OpenSky, DGCA punctuality reports).

Design wireframes (Figma or pen & paper).


### Week 3–4: Development

Build backend API calls to fetch & store flight data.

Create a dashboard to list flights & delays.

Add filters: Airline, route, date.

Show charts for delays (Chart.js/Recharts).

Deploy frontend & backend (Vercel + Railway).


📌 End of Month 1 Deliverable:
A hosted web app where users can see flight delay trends for budget airlines in India.


---

## Month 2 – Learn AI Fundamentals

Goal: Build the foundation to add predictions later.

Python basics refresher (if needed).

Learn Pandas, NumPy for data handling.

Learn Scikit-learn for machine learning.

Practice small datasets (Titanic dataset, weather prediction).

Understand model lifecycle: train → test → deploy.


📌 End of Month 2 Deliverable:
You can confidently train, test, and evaluate basic ML models.


---

## Month 3 – Add Basic AI to VimaanAI

Goal: First version of delay prediction.

Collect historical flight delay data (merge API + DGCA reports).

Clean & preprocess the dataset.

Train a basic model (Decision Tree / Random Forest).

Create a backend endpoint to serve predictions.

Connect frontend to show “Predicted Delay Probability”.


📌 End of Month 3 Deliverable:
Your app predicts delays (even if accuracy is basic) and displays them in real time.


---

## Month 4+ – Advanced AI & Real-Time Features

Goal: Make it a polished, recruiter-magnet project.

Upgrade model to XGBoost / LSTM for time-series.

Integrate live weather API for better accuracy.

Automate data updates (Cron jobs).

Add SMS/Email delay alerts.

Improve UI with airline comparison dashboards.

Buy a custom domain (vimaanai.com) and host final version.


📌 End of Month 4–5 Deliverable:
A branded, AI-powered, real-time flight delay predictor ready for portfolio/demo.


---

💡 If you follow this, you can put VimaanAI on your resume in Month 1, and by Month 4–5 it will be a project that really makes you stand out.
